NEW: Instant Alerts + "back up" alerts

Instant Alerts (Settings → Instant Alerts)
• Turn it on and your ThrillTrack alert server watches wait times every minute and sends a push, even when the app is closed — no more waiting for iOS's hourly background check.
• Covers Lightning Lane / Priority Pass watches, wait-time alerts (DAS/AAP alerts keep their Book / I Booked It buttons), and the new reopen alerts.
• The Settings row shows how many alerts the server is watching and when it last synced. If the server can't be reached, the app falls back to its own checks automatically.
• The server has to be set up once first (Apple push key + Deno Deploy) — see server/README.md.

Alert Me When It's Back Up
• A down or closed ride's detail sheet has "Alert Me When It's Back Up" (or "…When It Opens"). You get one notification when it's operating again. Watches show in My Day and last for today.

Please check:
• Settings → Instant Alerts on → allow notifications → status turns green ("Watching N alerts · synced just now").
• Set a wait alert above a ride's current wait, close the app — the push should arrive within about a minute.
• On a down ride, tap "Alert Me When It's Back Up" — it appears in My Day; Cancel removes it.
• Tap a pushed alert — it opens that ride; the DAS/AAP/Lightning Lane buttons still work from the push.
• You should get one alert per event, not two (server + app).
